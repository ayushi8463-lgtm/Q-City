Goal

Earn $2500 before you miss 5 contracts. Cash below $0 means bankruptcy.

Each contract is a message between two cities. It needs a minimum fidelity (pair quality) before its deadline. Buy upgrades as demand rises.

How to play

Click a dashed route to set up a link (free, but it expires). Click a city to build a repeater ($120). Cities in the middle of a route need one.

Links make pairs by chance, and pairs fade. A contract is delivered only when EVERY link on its route holds a pair at the same time, with high enough quality.

How the physics works here

Photons in fiber get lost exponentially: each kilometre costs a fixed fraction, so doubling a route length squares the odds against you. That is why long links almost never produce a pair.

A contract is delivered only when every link on its route holds a pair at the same time.

A stored pair sits in quantum memory and decays toward useless (fidelity 0.25) as time passes. Pairs below 0.70 are thrown away.

A repeater swaps entanglement: two pairs A-B and B-C become one pair A-C. Each swap can fail (90% success) and lowers fidelity, using the Werner-state rule F = F1·F2 + (1-F1)(1-F2)/3. Once a pair A-C meets the contract's minimum fidelity, the message is teleported and you get paid.

Purification burns two pairs to make one cleaner pair (the BBPSSW rule), so quality costs speed. Every repeater and upgrade has a running cost, and demand steps up every 150 seconds, so keep only what earns its place.

Links are free but temporary: fiber gets cut and equipment fails, so each link goes down after a while (longer links fail sooner) and you must set it up again.
